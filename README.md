# Проект автоматизации тестирования на Selenium + Python

## Описание проекта

Данный проект содержит автоматизированные тесты для веб-приложения ["Самокат"](https://qa-scooter.praktikum-services.ru/). 
Тесты написаны с использованием паттерна Page Object Model (POM) для обеспечения поддерживаемости и переиспользуемости кода.

## Стек технологий

- **Язык:** Python 3.13+
- **Фреймворк для тестирования:** PyTest
- **Инструмент автоматизации браузера:** Selenium WebDriver
- **Браузер:** Firefox (geckodriver)
- **Отчеты:** Allure

## Структура проекта

- `drivers/` — содержит исполняемый файл geckodriver для Firefox
- `locators/` — файлы с локаторами элементов для каждой страницы
- `pages/` — содержит базовый класс и Page Object'ы для страниц
- `tests/` — содержит тесты, сгруппированные по функциональности
- `.gitignore` — файл для исключения временных и служебных файлов из Git
